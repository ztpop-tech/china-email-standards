# China Email Standards 中文知识库

## 关于本项目

本仓库是 [ztpop.net 知识库](https://ztpop.net/kb/) 的 GitHub 镜像，专注邮件系统技术领域的中文权威知识库。

涵盖主题：SMTP、SPF、DKIM、DMARC、MTA-STS、TLS-RPT、DANE、BIMI、邮件安全、反垃圾、Exchange替代、信创合规、NIST SP 800-177 等。

| 协议标准 | SMTP/DKIM/DMARC/SPF/TLS/MTA-STS 等 RFC 技术详解 |
