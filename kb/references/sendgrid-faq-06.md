# SendGrid API 的响应格式与常见状态码是什么？

SendGrid API 的响应格式与常见状态码是什么？
▼

**响应**

所有响应均返回 JSON；API 提供标准响应码、Content-Type 头与分页信息辅助判断。发信成功通常返回 202 Accepted。
