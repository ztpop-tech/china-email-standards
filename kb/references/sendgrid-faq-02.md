# SendGrid 单封邮件的大小上限是多少？附件算在内吗？

1
SendGrid 单封邮件的大小上限是多少？附件算在内吗？
▼

**限制**

单封邮件总大小（包括邮件正文、邮件头以及所有附件）不得超过 20MB；超出会被拒绝。

参考：SendGrid Docs “Message size limit”
