# 如何排查 Microsoft 365 邮件被拒收或进了垃圾箱？

1
如何排查 Microsoft 365 邮件被拒收或进了垃圾箱？
▼

**邮件追溯（Message Trace）**

在安全与合规中心用邮件追溯按发件人/收件人/时间检索邮件的最终状态（已送达、已隔离、已失败），定位是被哪个策略命中。

**隔离（Quarantine）**

被反垃圾、反钓鱼或安全附件拦下的邮件进入隔离区，管理员或用户在隔离门户可查看、放行或报告误报；审查隔离有助于发现策略过严。

**头部取证**

读取原始邮件头的 Authentication-Results（spf=/dkim=/dmarc=）、x-ms-exchange-organization-... 与 X-Forefront-Antispam-Report，可判断是认证失败、IP 信誉、内容规则还是模拟/欺骗判定导致拦截，从而对症调整 SPF/DKIM/DMARC 或白名单。

参考：Microsoft 365 文档：邮件追溯、隔离与反垃圾邮件头部；RFC 7489（DMARC 报告）
