# 如何在 Microsoft 365 反垃圾策略里配置隔离保留天数？

1
如何在 Microsoft 365 反垃圾策略里配置隔离保留天数？
▼

**说明**

在反垃圾策略中，对某个垃圾过滤判定（如 Spam）选择“隔离消息”作为动作时，可以设定“在隔离区保留 N 天”（合法值 1–30）。到期未处理则邮件被删除且不可恢复。你可以为不同判定（Spam、高置信度钓鱼等）分别绑定不同的隔离策略，从而分别控制用户能否查看或请求释放。

参考：Microsoft Learn《Anti-spam protection》· learn.microsoft.com/microsoft-365/security/office-365-security/anti-spam-protection-about
