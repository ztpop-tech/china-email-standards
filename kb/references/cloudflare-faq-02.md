# 发送事务邮件（Email Sending）有哪几种接入方式？

1
发送事务邮件（Email Sending）有哪几种接入方式？
▼

**三种方式**

① Workers 的 EMAIL binding；② REST API；③ 经认证的 SMTP（smtps://smtp.mx.cloudflare.net:465）。可按应用形态任选。

参考：Cloudflare Email Service API 文档
