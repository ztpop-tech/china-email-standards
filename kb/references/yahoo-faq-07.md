# Yahoo 建议用 OPT-IN / 双重确认来建邮件列表吗？为什么？

1
Yahoo 建议用 OPT-IN / 双重确认来建邮件列表吗？为什么？
▼

**推荐双重确认订阅**

Yahoo 建议当用户订阅时，发送一封请其点击确认的邮件来完成 opt-in 双重确认。这能避免用户误签或被恶意代签，也能让列表不含不感兴趣的人、虚假地址或多数机器人。

**设定期望 + 清理无效地址**

订阅时应清晰告知用户会收到什么邮件、频率与样式；并定期清理无效收件人（监控硬/软退信与不活跃用户，用双重确认降低无效地址，及时向不活跃订阅者发再确认邮件）。Yahoo 明确反对购买名单或默认勾选 opt-in。

参考：Yahoo《Sender Best Practices》— Use OPT-IN method；Remove invalid recipients
