# 还没有做域名认证（Sender Authentication）就发信，邮件会去哪？

1
还没有做域名认证（Sender Authentication）就发信，邮件会去哪？
▼

**影响**

若未配置域名认证，发出的邮件很可能在收件方进入垃圾箱；完成 Domain Authentication 后收件方才会正常信任并投递。

参考：SendGrid Docs “Sender Authentication” 提示
