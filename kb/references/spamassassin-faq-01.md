# Apache SpamAssassin 是什么？

1
Apache SpamAssassin 是什么？
▼

**定义**

Apache 软件基金会旗下的 #1 开源反垃圾邮件平台，为管理员提供过滤器，用于分类并拦截垃圾邮件（非邀约群发邮件）。

参考：Apache SpamAssassin 官网 Welcome
