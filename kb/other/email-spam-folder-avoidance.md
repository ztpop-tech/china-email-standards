# 邮件投递优化：避免进入垃圾邮件文件夹的策略 — 内容优化、发送行为与基础设施

参考 Gmail 和 Outlook 投递最佳实践

邮件被投递到垃圾邮件文件夹是发件方最常见的问题之一。即使通过了 SPF/DKIM/DMARC 认证，邮件仍可能被接收方的反垃圾引擎判定为垃圾。本章梳理邮件避免被归类为垃圾邮件的完整策略。

## 邮件内容层面的优化

### 文本与 HTML 平衡

纯 HTML 邮件（无文本版本）被垃圾引擎判为垃圾的概率显著增加。必须始终提供 Multi-part 格式（text/plain + text/html）。text/plain 部分不应过于简单（如"请查看 HTML 版本"），而应是 HTML 版本的实质内容简化。

### 链接与图片策略

* 图片/文字比例控制在 40/60 以内，大量图片且少量文字的邮件高度可疑
* 邮件中的链接数不应超过 5-10 个。大量链接是垃圾邮件的典型特征
* 避免使用 URL 短链接（如 bit.ly、t.cn），这类链接被垃圾引擎广泛标记
* 链接目标域应为邮件发送域或与其相关的可信域

### 避免垃圾触发词

以下词汇在邮件正文和主题中应避免使用：

* 财务类："免费""点击这里""立即行动""限时优惠"
* 紧急类："紧急""最后机会""立即""警报"
* 诱导类："这不是垃圾邮件""保证""无需付出"
* 特殊符号：多个感叹号（!!!）、全部大写主题行、$符号

## 发送行为层面的优化

### 发送频率策略

发送频率应保持稳定的节奏，避免突发性的发送量激增。突然从每日 1 万封变为 10 万封的行为会触发接收方的速率限制和信誉权重调整。建议：

* 维持稳定的固定发送时间（如每天上午 9:00-10:00）
* 将批量发送分散在 2-4 小时内完成，而非 1 小时内全部发出
* 大促/高量活动前提前通过 Postmaster Tools 通知邮箱服务商

### 收件人列表维护

* **定期清理**：每季度移除 6 个月以上未打开邮件的订阅用户
* **Hard Bounce 立即移除**：硬弹回的邮箱地址立即从活跃列表删除
* **Complaint 用户标记**：标记投诉用户，防止同一用户被再次发送
* **确认订阅**：使用 Double Opt-in 确保每个收件人明确同意接收邮件
* **退订链接**：每封邮件底部必须包含 One-click 退订链接（RFC 8058）

## 认证和基础设施层面的优化

* **DMARC p=reject**：部署拒绝策略，防止域仿冒影响域信誉
* **BIMI**：品牌标识提高用户信任度和打开率
* **MTA-STS + TLS-RPT**：确保传输加密，报告传输问题
* **PTR 记录**：发送 IP 的 PTR 必须与发送域或 MX 域匹配
* **Feedback Loop (FBL)**：注册各邮箱服务商的投诉循环，及时处理投诉
