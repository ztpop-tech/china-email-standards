# 什么是 DMARC？它如何对抗钓鱼邮件？

1
什么是 DMARC？它如何对抗钓鱼邮件？
▼

**说明**

DMARC（基于域的消息认证、报告和符合性）是一套标准，让邮件发送方和接收方更容易判断某封邮件是否真正来自声称的发送方，并约定若不合法该如何处置。它使识别垃圾邮件与钓鱼邮件、将其挡在用户收件箱之外变得更容易。DMARC 允许双方协作共享所收发邮件的信息：发送方据此完善邮件认证基础设施，使全部邮件都能通过认证；域名合法所有者则可要求将伪造的垃圾/钓鱼邮件直接送入垃圾箱或彻底拒绝。

参考：DMARC.org FAQ · RFC 7489
