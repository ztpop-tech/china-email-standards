# 常见 SMTP 退信码含义如何速查？

1
常见 SMTP 退信码含义如何速查？
▼

**响应码分类规则**

SMTP 响应为首位数字决定类别，后两位为具体原因：

* `2xx` 成功（如 250 OK、235 认证成功）。
* `4xx` 临时失败：可重试，通常是对端资源/策略临时不可用。
* `5xx` 永久失败：不应再重试同一封，需人工或列表清洗处理。
* 增强状态码形如 `5.1.1`（RFC 3463），第一数同类别、后两级细化原因。

**4xx 临时错误速查**

* `421` 服务不可用/连接被限流关闭——降低发送速率、错峰重试。
* `450` 邮箱临时不可用（如邮箱锁定/磁盘满）——按队列退避重试。
* `451` 本地处理失败（如策略/反病毒临时异常）——重试并排查网关。
* `452` 存储空间不足——重试，长期需扩容或清理。

**5xx 永久错误速查**

* `550` 邮箱不可用/被拒（无此用户或策略拒绝）——校验地址，硬退请移出列表。
* `551` 用户非本地，需转发（已弃用语义）——检查路由配置。
* `552` 超出存储配额/邮件过大——联系收件人清理或缩小附件。
* `554` 交易失败/被识别为垃圾或伪造——检查 SPF/DKIM/DMARC 与内容信誉。

**处理建议**

区分对待以提升投递与列表质量：

* 对 4xx 采用指数退避重试（如 15m/1h/4h/12h），超过阈值转人工。
* 对 5xx 中的 550/551/552（地址/配额类）按硬退立即移出活跃列表。
* 对 554 等信誉类，先自查认证与内容，再通过对端反馈环（FBL）定位批次。
* 用 VERB/增强码与 Received 头辅助定位是哪一跳返回的失败。

参考：RFC 5321《SMTP》第 4.2 节响应码定义、RFC 3463 增强状态码（DSN）。
