# SMTP 增强状态码（如 4.2.1、5.1.1）是什么意思？如何根据状态码判断邮件问题？

1
SMTP 增强状态码（如 4.2.1、5.1.1）是什么意思？如何根据状态码判断邮件问题？
▼

**结构**

增强状态码（RFC 3463）是 class.subject.detail 三段点分格式。class：2=成功，4=暂态失败（可重试），5=永久失败（不应重试）；subject：1=地址/路由、2=邮箱/连接、3=邮件系统、4=网络、5=协议、6=媒体/内容、7=安全/策略；detail 进一步细分具体原因。

**常见码**

RFC 5248 注册了常用码：4.2.1（邮箱忙/超时，软退）、4.2.2（邮箱满）、4.3.1（系统资源不足）、5.1.1（未知收件人，硬退）、5.1.2（域不可达）、5.1.8（发件域无效）、5.2.1（邮箱禁用）、5.4.1（收方拒收）、5.7.1（策略拒绝/认证失败）、5.7.25（缺失有效 PTR）等。

**排查**

先看 class 区分暂态(4.x)与永久(5.x)；再看 subject 定位是地址/系统/内容/安全；结合 detail 与服务器日志。对 5.x 永久失败不应重试，需联系收件方或修正发信配置（如补全 PTR、对齐 SPF/DKIM）。

**注意**

增强状态码由接收方自由扩展，不同服务商 detail 含义略有差异；应以 RFC 5248 基础码为主，detail 仅作辅助。

参考：RFC 3463（增强状态码）；RFC 5248（常用码注册）
