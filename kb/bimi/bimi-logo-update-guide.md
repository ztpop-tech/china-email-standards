# 品牌焕新后如何更新 BIMI Logo——完整操作指南

## 概述

品牌焕新令人兴奋——新的配色、精炼的文字标识、终于称心的 Logo。但如果你的组织已经实施了 BIMI（品牌标识符邮件识别），Logo 变更就不只是设计工作那么简单了。它会触发一系列技术更新流程，涉及你的邮件认证体系、验证商标证书和 DNS 记录。

好消息是：如果你已经完成过 BIMI 部署，这些流程并不陌生。坏消息是：你不能简单地替换一个 SVG 文件就完事。本指南将带你走过每一个步骤。

## 第一步：摸清现状

在做出任何变更之前，先盘点当前的 BIMI 配置。一个完整的 BIMI 部署由以下几个相互依赖的组件构成：

* 已在强制级别（p=quarantine 或 p=reject）部署的 DMARC 策略
* 托管在可公开访问 URL 上的 SVG Tiny PS Logo 文件
* 由授权 CA 颁发的 VMC（验证商标证书）或 CMC（通用商标证书）
* 在发信域名的选择器子域名下发布的 BIMI DNS TXT 记录

当 Logo 变更时，SVG 文件发生变化。由于 VMC 或 CMC 在密码学上与特定 SVG 绑定，一旦换入新 Logo，原证书立即失效。这意味着更新流程必须按正确顺序执行，否则会导致认证失败或 Logo 从收件箱中消失。

首先，找到当前的 BIMI DNS 记录、证书详情（签发 CA、过期日期、管理邮箱或账户），以及最初申请证书时提交的原始商标或在先使用证明文件。这些信息你将再次用到。

## 第二步：准备更新后的 BIMI Logo 文件

BIMI 对 Logo 文件有严格要求。更新后的 Logo 必须符合 SVG Tiny PS（便携/安全）规范——与你原始 Logo 所遵循的标准相同。在开始其他步骤前，先确认新 Logo 文件的格式是否正确。

* 文件必须是 SVG Tiny PS 格式，而非标准 SVG
* Logo 必须为正方形（1:1 宽高比）
* 必须使用纯色不透明背景
* 文件不得包含脚本、动画或外部引用
* 文件大小应控制在邮箱客户端可顺利获取的范围内（建议 32KB 以下）

许多 CA 和 BIMI 工作组成员在正式提交前提供 SVG 验证工具。提交不合规的 SVG 将延迟证书签发流程。

## 第三步：更新商标证书

这是整个过程中最复杂的一步。你的 VMC（Gmail 蓝勾等主要客户端要求）或 CMC 与你的域名和特定 Logo 文件绑定。更换 Logo 意味着需要新的证书——不能修改已有证书。

### 需要重新提交的材料

CA 需要重新验证品牌对新 Logo 的权利。根据持有的证书类型不同，材料要求也有所不同：

#### VMC（验证商标证书）

必须提供覆盖新 Logo 的注册商标。商标必须处于有效状态，类别与你的业务相符，并在受支持的法域注册（如 USPTO、EUIPO、UKIPO 等）。如果新 Logo 与商标版本存在实质差异，你可能需要在证书签发前提交新的商标申请——这个过程可能需要数月。

#### CMC（通用商标证书）

通过在先使用证明文件来证明权利，而非注册商标。通常需要提供标注日期的营销材料、网站截图、产品包装或新闻报导，证明该 Logo 已在商业中使用。材料必须清晰显示更新后的 Logo，而非旧版本。

### 时间规划

VMC 签发时间因 CA 而异，但通常在材料齐全后几天到两周内。如果你需要先申请商标，请将商标注册时间纳入考量。CMC 签发因文档要求较轻通常更快，但仍需预留数个工作日。

在此期间，你有两种实际选择：保持旧 BIMI 记录和旧证书在线（原始 Logo 继续显示），或从 BIMI 记录中暂时移除证书引用。前者在条件允许时更推荐——它能在准备新证书期间维持收件箱中的品牌展示。

## 第四步：发布更新后的 BIMI DNS 记录

新 VMC 或 CMC 签发完成、新 SVG 文件已在 URL 上托管好后，就可以更新 BIMI DNS 记录了。这是最后一步，也通常是最直接的一步——前提是前面所有步骤都已就绪。

### BIMI TXT 记录结构

BIMI 记录作为 TXT 记录发布在以下位置：

```
default._bimi.yourdomain.com
```

记录值格式如下：

```
v=BIMI1; l=https://yourdomain.com/logo.svg;
a=https://yourdomain.com/certificate.pem
```

更新 `l=`（Logo URL）和 `a=`（权威/证书 URL）的值，指向新的 SVG 位置和新证书 PEM 文件。如果你自己托管证书，确保在更新 DNS 记录前新 PEM 文件已能在其 URL 上正常访问。

### DNS 传播与验证

发布后，等待 DNS 传播——根据你的 TTL 设置，通常在几分钟到 48 小时之间。传播完成后，使用 BIMI 检查工具验证记录是否正确解析、SVG 是否加载和验证通过、证书是否被检查工具识别。

向 Gmail 或 Apple Mail 账户（均支持 VMC 的 BIMI 显示）发送测试邮件，确认新 Logo 出现在收件箱中。请注意，邮箱客户端可能会缓存 Logo 一段时间，在确认存在问题之前请预留 1-2 天的观察期。

## 更新前需知

* **尽早与品牌团队协调**。越早拿到最终定稿且合规的 SVG，证书流程就能越早启动。
* **不要让现有证书在此期间过期**。如果当前证书在你等待新证书期间过期，即使 DNS 记录仍在线，Logo 也会从收件箱消失。
* **使用暂存选择器进行测试**。你可以通过命名选择器发布第二条 BIMI 记录（如 `test._bimi.yourdomain.com`），在切换前测试新配置。
* **保持文档有序**。你提交的商标或在先使用证明文件将成为未来续期或更新的参考基准，存放在容易找到的地方。

## 总结

品牌焕新后更新 BIMI Logo 是一个多步骤流程，但完全可以管理。核心顺序始终不变：准备合规 SVG → 获得基于新的商标或在先使用证据的新证书 → 更新 DNS 记录指向两者。把这三件事做对，你的新 Logo 就能在每个支持 BIMI 的收件箱中展现验证和信任的标识。

### 国内场景补充

中国企业在进行 BIMI Logo 更新时需特别注意：目前中国大陆尚无支持的商标局被列入 BIMI VMC 的受支持管辖区列表。因此国内企业选择 CMC（通用商标证书，在先使用证明）而非 VMC 更为可行。准备在先使用证明材料时，建议收集微信公众号文章截图、淘宝/京东店铺页面、工信部 ICP 备案证明材料等作为品牌使用证据。
